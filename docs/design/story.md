# 게임 스토리 기획

## 세계관 (확정)
**무지개 마을** — 파스텔톤의 아늑한 마을. 정해진 결말 없이 꾸미고 돌아다니는 것 자체가
목적. (2, 3번 후보는 시즌 확장 아이디어로 보류)

## 핵심 루프 (매일 들어오고 싶게 만드는 순환)
캐릭터 꾸미기 → 마을 돌아다니기(걷기, 카메라 구경) → 짧은 미니 미션 완료
(친구 만나기, 심부름) → 보상으로 새 옷/아이템 획득 → 다시 꾸미기

## MVP 스토리 범위
- 오프닝: 짧은 환영 인사 + 조작법 안내를 겸한 튜토리얼
- 정해진 엔딩 없음. 라이프심(생활 시뮬레이션) 스타일의 오픈형 구조
- 스토리는 장식적 역할, 메인은 꾸미기/수집

## 톤 & 원칙
- 항상 다정하고 안전한 어휘
- 경쟁/비교 요소 최소화 (순위, 남과 비교 금지)
- 협동, 수집, 꾸미기 중심의 동기부여

---

## 플레이어 캐릭터 — 손유나
- 자운초등학교 재학
- 귀여운 동물(강아지, 고양이 등) 좋아함 — *추후 확장: 반려동물 동행 시스템 후보*
- 활발하고 신나게 노는 것을 좋아함 — 놀이터/미니게임 요소와 궁합이 좋음
- 똑부러지고 똑똑하며 배려심 많고 집안일도 잘 도움 — NPC 대사에 "유나는 참 야무지네"
  같은 반응으로 성격을 반영
- 키가 작지만 아주 귀여움 — 캐릭터 기본 체형을 다른 성인 NPC보다 살짝 작게 설정

## 가족 NPC — MVP에 포함 (우리집)
| 이름 | 관계 | 설정 | 마을 역할 |
|---|---|---|---|
| 손용석 | 아빠 | 회사원, 매일 아침 명상·운동, 몸매 좋고 안정적이며 재미있음 | **아침 운동 공원** 담당 — 아침 시간대 미션 안내 |
| 조수정 | 엄마 | 먹을 것·입을 것·공부를 두루 챙김 | **옷가게** 담당 — 새 옷 언락 지점 (드레스업 핵심 상점과 자연스럽게 연결) |
| 손유림 | 언니 | 중학생, 키 크고 춤을 잘 추고 좋아함, 공부도 잘함 | **댄스 광장** 담당 — 같이 춤추는 미니 인터랙션 |

엄마가 옷가게를 맡는 설정은 실제 코어 메커닉(옷 갈아입히기)과 스토리를 자연스럽게
엮어주는 지점이라 MVP에서 가장 먼저 구현할 우선순위로 추천합니다.

## 확장 마을 주민 — MVP 이후 2차 콘텐츠 (구역별)

**친가 구역**
| 이름 | 관계 |
|---|---|
| 손상용 | 할아버지 |
| 최두리 | 할머니 |
| 손장훈 | 큰아빠 |
| 손기쁨 | 사촌 (큰아빠 딸) |
| 손수정 | 고모 |
| 이경호 | 고모부 |
| 이주헌 | 사촌 (고모 아들) |
| 이소은 | 사촌 (고모 딸) |

**외가 구역**
| 이름 | 관계 |
|---|---|
| 조일현 | 외할아버지 |
| 이성숙 | 외할머니 |
| 조은 | 이모 |
| 조규진 | 작은이모 |
| 이수남 | 이모부 |
| 이윤성 | 사촌 (작은이모 아들) |

역할(어떤 건물/미니게임을 맡을지)은 다음 기획 때 정하기. 우선 후보:
- 할아버지·할머니 → "할머니댁 정원" (한적한 산책/휴식 구역)
- 큰아빠·손기쁨 → "사촌네 놀이터" (활동적인 미니게임)
- 고모·고모부·이주헌·이소은 → "고모네 마당"
- 외할아버지·외할머니 → "외갓집 텃밭" (수확/채집형 미니게임 후보)
- 이모·작은이모·이모부·이윤성 → 역할 미정

## 마을 구역(존) 배치
- 중심 광장 (튜토리얼 + 메인 상점)
- 우리집 구역 — 아빠/엄마/언니 (MVP 범위)
- 친가 구역 (2차 콘텐츠)
- 외가 구역 (2차 콘텐츠)
